## 1. 产品概述

构建日文界面的「勤怠・タスク管理」迷你后台，用于练习 AI Agent 在约束下按 4p12s 可靠交付。

### 1.1 本期范围（摘要）

- 认证、タスク CRUD 与**状态机**（见 §4.1）
- 打刻：**一覧閲覧**与**日次集計**（只读）
- 打刻示例数据由 **DB seed** 提供；**不含**用户出勤/退勤打刻操作

### 1.2 本期明确不做

- 出勤/退勤打刻 UI 与 `POST /api/attendance`（后续需求另开）
- 多租户、SSO、审批流、更换固定技术栈

## 2. 目标与成功标准

- 用户可登录，**管理タスク**（含合法状态迁移），**閲覧・集計打刻記録**
- 时区行为正确（UTC / Asia/Tokyo）
- 质量门禁：单测 → 集成 → E2E → Git → 部署证据链可走通

## 3. 角色

- ログイン済みユーザー
- （系统）未登录访问者 → 保護ページアクセス時はログイン画面へ（AC-016）

### 4.1 业务规则（任务状态机）

| ID | 规则 |
|----|------|
| BR-007 | 状态枚举：`todo`（未着手）、`in_progress`（進行中）、`done`（完了）；新建默认 `todo` |
| BR-008 | **允许**：`todo`→`in_progress`；`in_progress`→`done`；`in_progress`→`todo` |
| BR-009 | **禁止**：`todo`→`done`；`done`→任意状态；违反时 API/UI 返回 400 级错误与日文说明 |

状态流转图：

```
todo ──→ in_progress ──→ done
  ↑            │
  └────────────┘（回退可）
```
