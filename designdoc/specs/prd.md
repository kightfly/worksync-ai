## 1. 产品概述

日文界面的「勤怠・タスク管理」迷你后台，供ログイン済みユーザー管理个人タスク，并閲覧打刻記録与日次集計。系统用于练习 **AI Agent 在 4p12s 约束下可靠交付**，非生产级多租户 SaaS。

**本期价值**：
- 完成认证 → タスク管理 → 打刻閲覧的端到端主路径
- 状态机与只读打刻等业务规则在 Domain 层可验证
- 单测 → 集成 → E2E → 部署证据形成可审计交付链

---

## 2. 目标与成功标准

| 目标 | 成功标准（可验证） |
|------|-------------------|
| 安全访问 | 未登录无法访问业务 API/页面（AC-016）；密码不明文存储（NFR-002） |
| タスク管理 | CRUD + 状态机符合 BR-007～009；非法迁移返回 400（AC-006、AC-012） |
| 打刻閲覧 | 一覧 Tokyo 展示；日次集計与 seed 边界一致（AC-008、AC-009、AC-015） |
| 日文体验 | UI/错误/空态为日文（BR-006）；关键文案见 AC-010、AC-014 |
| 交付质量 | Vitest 单测 + 真 DB 集成 + Playwright E2E 主路径通过（NFR-005） |

**本期不做**（见登记表 §1.2）：打刻录入 API、多租户/SSO/审批、`done` 任务 PATCH。

## 6. 非功能需求

| ID | 类别 | 要求 | 验证方式 |
|----|------|------|----------|
| NFR-001 | 性能 | 页面加载 < 2s；API 响应 < 500ms（目标） | 手动/性能抽样；非 E2E 阻塞项 |
| NFR-002 | 安全 | bcrypt 密码哈希；JWT 鉴权；防注入/XSS | 单测 + 代码审查 |
| NFR-003 | 质量 | 覆盖率目标 80%+；TS strict；ESLint | CI `lint`/`typecheck`/`test` |
| NFR-004 | 时区 | DB UTC；展示 Asia/Tokyo；API ISO 8601 `+09:00` | 集成测试 + AC-008 |
| NFR-005 | 测试 | E2E 主路径必过；集成/E2E 禁 Mock 假完成 | Playwright + verification-result |
| NFR-006 | 国际化 | UI・错误・空态为日文 | AC-002、010、011、012、014、017 |
| NFR-007 | 架构 | 固定技术栈；UI→API→Domain→Infrastructure | AGENTS.md、design（⑤） |

## 7. 验收口径（产品级）

> 细节 Given/When/Then 见 ④ `user-stories.md`。下表为 PRD 级可测试陈述。

### 7.1 认证（F-001～F-003）

| AC | 可测试陈述 |
|----|-----------|
| AC-001 | 输入 `test@example.com` + `password123` 登录成功，浏览器 URL 为 `/dashboard` 或业务页 |
| AC-002 | 空邮箱或无效格式提交后，页面显示日文校验/错误，不进入业务页 |
| AC-011 | 正确邮箱 + 错误密码时，显示「メールアドレスまたはパスワードが正しくありません」，且不区分邮箱是否存在 |
| AC-003 | 点击ログアウト后，会话清除，跳转 `/login` |
| AC-016 | 未带 token 访问 `/tasks` 等保护路由，重定向至 `/login` |

### 7.2 タスク（F-005～F-008）

| AC | 可测试陈述 |
|----|-----------|
| AC-004 / AC-017 | 创建时标题为空则 API 400 或前端阻止提交，并显示日文提示 |
| AC-005 | 一覧按 `created_at` 降序；每行可见 `status` |
| AC-010 | 无任务时显示「タスクはありません」 |
| AC-006 | `todo`→`in_progress` 成功；响应含新状态 |
| AC-012 | `todo`→`done` 请求返回 400，body 含 `INVALID_STATE_TRANSITION` 与「無効な状態遷移です」 |
| AC-007 | 点击削除弹出確認；キャンセル后任务仍在一覧 |
| AC-013 | 確認削除后任务从一覧消失 |

### 7.3 打刻（F-009～F-010）

| AC | 可测试陈述 |
|----|-----------|
| AC-008 | 一覧中 check_in/check_out 以 Tokyo 偏移展示 |
| AC-014 | 无记录时显示「打刻記録はありません」 |
| AC-009 | 日次集計工时与 seed 预期一致 |
| AC-015 | 跨日记录按出勤日 `work_date` 归入正确日期 |

## 9. 风险与接受边界

| 风险 | 影响 | 缓解 / 接受边界 |
|------|------|----------------|
| 性能目标无自动门禁 | NFR-001 难量化 | 接受为参考目标；不以压测失败阻塞 MVP |
| 单用户演示 | 无多用户隔离测试 | 本期仅单租户单用户 seed；多租户明确不做 |
| `done` 任务不可编辑 | 用户期望变更 | 本期接受；登记表已排除 PATCH |
| E2E 环境依赖 DB | ⑩ 可能 flaky | ⑨ 集成先验真 DB；E2E 用同一 seed |
| 无打刻录入 | 演示数据固定 | BR-010 已确认只读 |
