# TASK-C301～C304: 任务 API

## 元信息

- 标题：Task CRUD API（JWT 保护）
- 状态：done
- 依赖：C201、B204 TaskRepository
- 对应：US-010～013 / V-010～V-016

## 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tasks` | 列表（可选 `?status=`） |
| POST | `/api/tasks` | 创建（201） |
| PATCH | `/api/tasks/:id` | 更新（含状态机） |
| DELETE | `/api/tasks/:id` | 删除（204） |

均需 `Authorization: Bearer <token>`。

## 实现

| 组件 | 路径 |
|------|------|
| JWT 中间件 | `apps/api/src/plugins/authenticate.ts` |
| TaskService | `apps/api/src/services/task.service.ts` |
| 路由 | `apps/api/src/routes/tasks.ts` |
| 校验 | `apps/api/src/schemas/task.schema.ts` |

## 错误映射

| 场景 | HTTP | error |
|------|------|-------|
| 未认证 | 401 | `UNAUTHORIZED` |
| 校验失败 | 400 | `VALIDATION_ERROR` |
| 非法状态迁移 | 400 | `INVALID_STATE_TRANSITION` |
| done 任务修改 | 400 | `TASK_LOCKED` |
| 任务不存在 | 404 | `NOT_FOUND` |
