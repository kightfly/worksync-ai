# TASK-C401～C402: 打刻只读 API

## 元信息

- 标题：Attendance 一覧 / 集計 API
- 状态：done
- 依赖：B205 AttendanceRepository、C201/C202 认证 API
- 对应：US-020 / US-021 / V-020 / V-021

## 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/attendance` | 日期范围内打刻一覧 |
| GET | `/api/attendance/statistics` | 日次工时集計 + 期间合计 |

均需 `Authorization: Bearer <token>`。

## 实现

| 组件 | 路径 |
|------|------|
| Service | `apps/api/src/services/attendance.service.ts` |
| Route | `apps/api/src/routes/attendance.ts` |
| Query 校验 | `apps/api/src/schemas/attendance.schema.ts` |
| Tokyo 映射 | `apps/api/src/lib/attendance-mapper.ts` |

## 契约

### `GET /api/attendance`

- 200：`{ records: [...] }`
- 401：`UNAUTHORIZED`
- 400：`VALIDATION_ERROR`

返回时间以 **Asia/Tokyo** 输出，带 `+09:00` 偏移。

### `GET /api/attendance/statistics`

- 200：`{ dailyStats: [...], totalHours }`
- 401：`UNAUTHORIZED`
- 400：`VALIDATION_ERROR`
