## 目标

集中实现 UTC ↔ Asia/Tokyo 转换、以及「出勤瞬间 → `work_date`（Tokyo 日历日）」纯函数；供 API 输出 `+09:00` 与集計使用。

## 边界（做 / 不做）

- **做**：共享日期工具 + 单测（含东京 0 点前后跨日）
- **不做**：DB 读写、HTTP

## 涉及文件

- `packages/domain` 或 `packages/infrastructure` 下共享 `datetime` 工具（优先无框架依赖，放 domain/util 亦可）
- `*.test.ts`

## 失败测试（红灯意图）

- 给定 UTC 瞬间，格式化为带 `+09:00` 的 ISO
- 跨日：东京 23:00 出勤、翌日退勤 → `work_date` 仍为出勤日
- 禁止依赖「服务器本地时区」隐式行为
