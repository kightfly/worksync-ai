## 故事列表

### 认证域

#### US-001: ログイン

```
作为 未ログインユーザー
我想要 メールアドレスとパスワードでログインする
以便 勤怠・タスク管理画面を利用できる

Given ログイン画面 `/login` を開いている
  And Seed ユーザー `test@example.com` / `password123` が存在する
When 正しいメールアドレスとパスワードを入力してログインする
Then `/dashboard` に遷移する
  And 認証状態が保持される
```

- 关联：F-001、F-004 / AC-001 / BR-001、BR-002、BR-006
- 场景类型：主流程
- UI 要点：ログインフォーム；ボタン「ログイン」

**子场景 US-001b（校验失败）**

```
Given ログイン画面を開いている
When メールアドレスが空、または形式が不正のまま送信する
Then 日文のバリデーション／エラーが表示される
  And 業務画面へ遷移しない
```

- 关联：AC-002 / BR-001
- 场景类型：异常 / 边界

**子场景 US-001c（错误密码）**

```
Given ログイン画面を開いている
When 正しいメールと誤ったパスワードでログインする
Then 「メールアドレスまたはパスワードが正しくありません」が表示される
  And メールの有無を推測できる文言は出さない
```

- 关联：AC-011
- 场景类型：异常

---

#### US-002: ログアウト

```
作为 ログイン済みユーザー
我想要 ログアウトする
以便 セッションを終了し他者が使えないようにする

Given ダッシュボード等の業務画面にログイン済みである
When ユーザーメニューから「ログアウト」を実行する
Then `/login` に遷移する
  And 保護ページへ戻ろうとすると再ログインが必要になる
```

- 关联：F-002 / AC-003
- 场景类型：主流程
- UI 要点：右上ユーザーメニュー「ログアウト」

---

#### US-003: ルートガード

```
作为 未ログインユーザー
我想要 保護ページに直接アクセスできない
以便 未認証で業務データが見られない

Given 有効な認証トークンを持っていない
When `/dashboard`、`/tasks`、または `/attendance` を開く
Then `/login` へリダイレクトされる
```

- 关联：F-003 / AC-016
- 场景类型：异常
- UI 要点：N/A（リダイレクト）

---

### タスク域

#### US-010: タスク作成

```
作为 ログイン済みユーザー
我想要 新しいタスクを作成する
以便 作業を一覧で管理できる

Given `/tasks` を開いている
When タイトルを入力して作成する
Then タスクが一覧に現れ、status は `todo` である
```

- 关联：F-006 / AC-004 / BR-003、BR-007
- 场景类型：主流程
- UI 要点：新規ポップアップ；タイトル必須

**子场景 US-010b（空标题）**

```
Given タスク作成フォームを開いている
When タイトルを空のまま送信する
Then 日文のエラー／バリデーションが表示される
  And タスクは作成されない（フロント阻止または API 400）
```

- 关联：AC-004、AC-017 / BR-003
- 场景类型：边界 / 异常

---

#### US-011: タスク一覧

```
作为 ログイン済みユーザー
我想要 自分のタスクを一覧で見る
以便 状態と内容を把握できる

Given ログイン済みで複数タスクが存在する
When `/tasks` を開く
Then タスクが作成日時の降順で表示される
  And 各行に status が見える
```

- 关联：F-005 / AC-005
- 场景类型：主流程
- UI 要点：表格式一覧；状态列

**子场景 US-011b（空态）**

```
Given ログイン済みでタスクが 0 件である
When `/tasks` を開く
Then 「タスクはありません」と表示される
```

- 关联：AC-010；Q-001 已关闭
- 场景类型：空态

---

#### US-012a: 状态迁移 todo → in_progress

```
作为 ログイン済みユーザー
我想要 タスクを着手中にする
以便 進行状況を反映できる

Given status が `todo` のタスクがある
When status を `in_progress` に更新する
Then 更新が成功し、一覧／詳細で `in_progress` と見える
```

- 关联：F-007 / AC-006 / BR-008
- 场景类型：主流程

---

#### US-012b: 状态迁移 in_progress → done

```
Given status が `in_progress` のタスクがある
When status を `done` に更新する
Then 更新が成功し、status は `done` になる
```

- 关联：F-007 / AC-006 / BR-008
- 场景类型：主流程

---

#### US-012c: 状态迁移 in_progress → todo

```
Given status が `in_progress` のタスクがある
When status を `todo` に戻す
Then 更新が成功し、status は `todo` になる
```

- 关联：F-007 / AC-006 / BR-008
- 场景类型：主流程

---

#### US-012d: 非法迁移 todo → done

```
Given status が `todo` のタスクがある
When status を `done` に更新しようとする
Then API は 400 を返す
  And エラーコード `INVALID_STATE_TRANSITION` と
      日文「無効な状態遷移です」が返る／表示される
  And タスクの status は `todo` のまま
```

- 关联：F-007 / AC-012 / BR-009
- 场景类型：异常 / 边界

---

#### US-012e: 非法迁移 done → 任意 / 内容更新禁止

```
Given status が `done` のタスクがある
When status を変更する、またはタイトル等を PATCH しようとする
Then 更新は拒否される（400 または同等）
  And タスク内容・status は変わらない
```

- 关联：F-007 / BR-009；登记表 §1.2「done 禁止 PATCH」
- 场景类型：异常 / 边界

---

#### US-012f: 内容更新（非 done）

```
作为 ログイン済みユーザー
我想要 未完了タスクのタイトル／説明を編集する
以便 内容を最新に保てる

Given status が `todo` または `in_progress` のタスクがある
When タイトルまたは説明を更新する
Then 変更が保存され、一覧に反映される
```

- 关联：F-007 / BR-007
- 场景类型：主流程
- UI 要点：編集ポップアップ

---

#### US-013: タスク削除

```
作为 ログイン済みユーザー
我想要 不要なタスクを削除する
以便 一覧を整理できる

Given `/tasks` に対象タスクが表示されている
When 削除を選び、確認ダイアログで「確認／削除」する
Then タスクが一覧から消える
```

- 关联：F-008 / AC-013；Q-002 已关闭
- 场景类型：主流程
- UI 要点：確認ダイアログ（削除確認）

**子场景 US-013b（キャンセル）**

```
Given 削除確認ダイアログが表示されている
When 「キャンセル」する
Then ダイアログが閉じ、タスクは一覧に残る
```

- 关联：AC-007
- 场景类型：异常（用户取消）

### 打刻域

#### US-020: 打刻一覧

```
作为 ログイン済みユーザー
我想要 打刻記録を一覧で見る
以便 出勤・退勤時刻を確認できる

Given Seed に打刻記録がある
When `/attendance` を開く
Then 各レコードの時刻が Asia/Tokyo（例: `+09:00`）で表示される
```

- 关联：F-009 / AC-008 / BR-004、BR-010
- 场景类型：主流程
- UI 要点：打刻一覧（只读）；无录入按钮

**子场景 US-020b（空态）**

```
Given 当該ユーザーに打刻記録が 0 件である
When `/attendance` を開く
Then 「打刻記録はありません」と表示される
```

- 关联：AC-014
- 场景类型：空态

---

#### US-021: 日次集計

```
作为 ログイン済みユーザー
我想要 日ごとの勤務時間集計を見る
以便 日次の工数を把握できる

Given Seed に日次集計可能な打刻がある
When `/attendance` で日次集計を表示する
Then 各 work_date の工時が Seed 期待値と一致する
```

- 关联：F-010 / AC-009、AC-015 / BR-004、BR-005
- 场景类型：主流程 / 边界

**子场景 US-021b（跨日 work_date）**

```
Given 出勤が Tokyo カレンダー日 D、退勤が翌日にまたがる記録がある
When 日次集計を見る
Then 当該工時は出勤日 `work_date` = D に集計される
```

- 关联：AC-009、AC-015
- 场景类型：边界

Then 2xx が返り、認証は不要である
