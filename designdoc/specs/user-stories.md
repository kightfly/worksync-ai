## 1. 用户认证

### US-001: 用户登录

```
作为 ユーザー
我想要 メールとパスワードでログインする
以便 タスクと打刻にアクセスする

Given ログイン画面を開いている
When 有効なメールと6文字以上のパスワードを送信する
Then タスク一覧へ遷移する

Given ログイン画面を開いている
When 無効なメール形式または6文字未満のパスワードを送信する
Then バリデーションエラーが表示され、ログインしない

Given ログイン画面を開いている
When 形式は正しいが登録と一致しないメール/パスワードを送信する
Then「メールアドレスまたはパスワードが正しくありません」と表示され、ログインしない
```

- 关联：F-001 / AC-001 / AC-002 / AC-011 / BR-001 / BR-002
- 场景类型：主流程 + 异常
- UI 要点：メール・パスワード必須；统一失败文案不透露邮箱是否存在

### US-002: 用户登出

```
作为 ユーザー
我想要 ログアウトする
以便 アカウントを保護する

Given ログイン済みである
When ログアウト操作をする
Then ログイン画面へ遷移し、認証状態がクリアされる
```

- 关联：F-002 / AC-003
- 场景类型：主流程

### US-003: 未登录访问保护页

```
作为 未ログインユーザー
我想要 保護されたページに直接アクセスしない
以便 認証が必要な機能だけが使える

Given ログインしていない
When タスク一覧や打刻一覧など保護ページの URL を開く
Then ログイン画面へリダイレクトされる
```

- 关联：F-001 / AC-016
- 场景类型：异常 / 安全

## 2. タスク管理

### US-010: 创建任务

```
作为 ユーザー
我想要 新しいタスクを作成する
以便 仕事を管理する

Given タスク作成フォームを開いている
When タイトル（必須）と任意の期限・説明を保存する
Then タスク一覧に新しいタスクが表示され、状態は todo である

Given タスク作成フォームを開いている
When タイトルを空のまま保存しようとする
Then「タイトルは必須です」等のエラーが表示され、作成されない
```

- 关联：F-003 / AC-004 / AC-017 / BR-003
- 场景类型：主流程 + 异常

### US-011: 查看任务列表

```
作为 ユーザー
我想要 タスク一覧を見る
以便 仕事を把握する

Given ログイン済みでタスクが1件以上ある
When タスク一覧を開く
Then 全タスクが作成日時の降順で表示され、状態（todo/in_progress/done）が見える

Given ログイン済みでタスクが一件もない
When タスク一覧を開く
Then「タスクはありません」と表示される
```

- 关联：F-004 / AC-005 / AC-010
- 场景类型：主流程 + 空态

### US-012: 更新任务

**US-012a 开始任务（todo → in_progress）**

```
Given 状態が todo のタスクがある
When 状態を in_progress に更新する
Then 一覧に in_progress と表示される
```

**US-012b 完成任务（in_progress → done）**

```
Given 状態が in_progress のタスクがある
When 状態を done に更新する
Then 一覧に done と表示される
```

**US-012c 回退任务（in_progress → todo）**

```
Given 状態が in_progress のタスクがある
When 状態を todo に戻す
Then 一覧に todo と表示される
```

**US-012d 更新标题与说明（任意状态）**

```
Given 既存タスクがある
When タイトルまたは説明を更新する（状態は変更しない）
Then 一覧に直ちに反映される
```

**US-012e 非法状态迁移（异常）**

```
Given 状態が todo のタスクがある
When 状態を done に直接更新しようとする
Then 400 相当のエラーと「無効な状態遷移です」等の日文メッセージが返り、状態は変わらない

Given 状態が done のタスクがある
When 状態を todo または in_progress に変更しようとする
Then 400 相当のエラーと日文メッセージが返り、状態は変わらない
```

- 关联：F-005 / AC-006 / AC-012 / BR-007～BR-009
- 场景类型：主流程 + 异常

### US-013: 删除任务

```
作为 ユーザー
我想要 不要なタスクを削除する
以便 一覧を整える

Given 既存タスクがある
When 削除を選び、確認ダイアログで「削除」を選ぶ
Then 一覧から除去される

Given 既存タスクがある
When 削除を選び、確認ダイアログで「キャンセル」を選ぶ
Then タスクは一覧に残る
```

- 关联：F-006 / AC-007 / AC-013
- 场景类型：主流程 + 边界
- UI 要点：削除前**確認ダイアログ（モーダル）**（Q-002 已决议）

### US-020: 打卡列表

```
作为 ユーザー
我想要 打刻記録を見る
以便 出勤履歴を確認する

Given ログイン済みで seed により打刻記録が存在する
When 打刻一覧を開く
Then 打刻時刻が Asia/Tokyo で表示され、勤務日とともに日付降順で並ぶ

Given ログイン済みで打刻記録が一件もない
When 打刻一覧を開く
Then「打刻記録はありません」と表示される
```

- 关联：F-007 / AC-008 / AC-014 / BR-004 / BR-010
- 场景类型：主流程 + 空态

### US-021: 打卡统计

```
作为 ユーザー
我想要 日次の勤務時間集計を見る
以便 働いた時間を把握する

Given seed により複数日の打刻データがある
When 集計ビューを開く
Then 日ごとの勤務時間と期間合計が正確に表示される

Given 出勤が東京 2024-01-15 23:00、退勤が東京 2024-01-16 02:00 の記録がある（work_date=2024-01-15）
When 2024-01-15 の日次集計を見る
Then 当該日の勤務時間は check_out - check_in（約3時間）であり、work_date は出勤日のまま集計される
```

- 关联：F-008 / AC-009 / AC-015 / BR-005
- 场景类型：主流程 + 边界（跨日・时区）
