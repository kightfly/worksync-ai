## 1. 用户认证

### US-001: 用户登录

```
作为 ユーザー
我想要 メールとパスワードでログインする
以便 タスクと打刻にアクセスする

Given ログイン画面を開いている
When 有効なメールと6文字以上のパスワードを送信する
Then タスク一覧へ遷移する

Given ログイン画面を開いている
When 無効なメールまたは短すぎるパスワードを送信する
Then エラーメッセージが表示され、ログインしない
```

- 关联：F-001 / AC-001 / AC-002
- 场景类型：主流程 + 异常
- UI 要点：メール・パスワード必須；日文错误提示

### US-002: 用户登出

```
作为 ユーザー
我想要 ログアウトする
以便 アカウントを保護する

Given ログイン済みである
When ログアウト操作をする
Then ログイン画面へ遷移し、認証状態がクリアされる
```

- 关联：F-002 / AC-003
- 场景类型：主流程

## 2. タスク管理

### US-010: 创建任务

```
作为 ユーザー
我想要 新しいタスクを作成する
以便 仕事を管理する

Given タスク作成画面/フォームを開いている
When タイトル（必須）と任意の期限・説明を保存する
Then タスク一覧に新しいタスクが表示される
```

- 关联：F-003 / AC-004 / BR-003
- 场景类型：主流程

### US-011: 查看任务列表

```
作为 ユーザー
我想要 タスク一覧を見る
以便 仕事を把握する

Given ログイン済みである
When タスク一覧を開く
Then 全タスクが作成日時の降順で表示され、状態（todo/in_progress/done）が見える

Given タスクが一件もない
When タスク一覧を開く
Then 空态が分かる（文案 Q-001 待确认）
```

- 关联：F-004 / AC-005 / AC-010
- 场景类型：主流程 + 空态

### US-012: 更新任务

```
作为 ユーザー
我想要 タスク状態や内容を更新する
以便 進捗を追跡する

Given 既存タスクがある
When 状態・タイトル・説明を更新する
Then 一覧に直ちに反映される
```

- 关联：F-005 / AC-006
- 场景类型：主流程

### US-013: 删除任务

```
作为 ユーザー
我想要 不要なタスクを削除する
以便 一覧を整える

Given 既存タスクがある
When 削除を選び、確認後に確定する
Then 一覧から除去される
```

- 关联：F-006 / AC-007
- 场景类型：主流程 / 边界（确认取消则不删）
- UI 要点：削除前確認（形态 Q-002）

## 3. 打刻

### US-020: 打卡列表

```
作为 ユーザー
我想要 打刻記録を見る
以便 出勤を確認する

Given ログイン済みである
When 打刻一覧を開く
Then 打刻時刻が Asia/Tokyo で表示され、勤務日とともに日付降順で並ぶ
```

- 关联：F-007 / AC-008 / BR-004
- 场景类型：主流程

### US-021: 打卡统计

```
作为 ユーザー
我想要 日次の勤務時間集計を見る
以便 働いた時間を把握する

Given 打刻データがある
When 集計ビューを開く
Then 日ごとの勤務時間と合計が正確に表示される
```

- 关联：F-008 / AC-009
- 场景类型：主流程 / 边界（跨日・时区）
