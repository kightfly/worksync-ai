## 5. 约束

| 类别 | 约束 | 来源 |
|------|------|------|
| 技术栈 | React 19 + Vite / Fastify / PostgreSQL + Drizzle / Vitest + Playwright；**不可擅自更换** | AGENTS.md、整体设计 §2 |
| 模块边界 | UI → API → Domain → Infrastructure；Domain 无外部依赖 | 整体设计 §2.2 |
| 时区 | DB UTC；展示 Asia/Tokyo；API 时间输出 ISO 8601 带 `+09:00` | BR-004/005、整体设计 §6.2 |
| 语言 | 代码、UI、种子数据、错误提示为**日文** | AGENTS.md、BR-006 |
| 认证 | JWT + bcrypt（`SALT_ROUNDS=10`）；密码 ≥ 6 字符 | 整体设计 §2 |
| 性能目标 | 页面 < 2s；API < 500ms（NFR-001） | 整体设计 §7 |
| 安全 | 密码哈希；防注入；XSS；JWT 鉴权（NFR-002） | 整体设计 §7 |
| 质量 | 覆盖率目标 80%+；TS strict；ESLint（NFR-003） | 整体设计 §7 |
| 测试 | E2E 主路径必过；禁 Mock 假完成（NFR-005） | 整体设计 §7 |
| 脚手架 | ⑧ 前不创建 `apps/`、`packages/`、根 `package.json` | delivery-state 护栏约定 |
| Seed | 演示账号 `test@example.com` / `password123` / `テストユーザー` | 整体设计 §6.3 |
