## 测试金字塔

```
        ┌─────────┐
        │  E2E    │  ← Playwright（交付门禁；禁 Mock 全链路）
        │  少量    │
       ┌┴─────────┴┐
       │ 集成测试    │  ← Vitest + 真实 DB / 真实 API
       │  适量      │
      ┌┴───────────┴┐
      │  单元测试     │  ← Vitest（业务逻辑必测）
      │  大量        │
      └─────────────┘
```

> **假完成**（`4p12s-gates.mdc` / `verification-before-completion`）：只跑单测、或 E2E/集成全 Mock，**不得**宣称 4p12s 交付完成。

## TDD 规则

遵循 `.cursor/rules/tdd.mdc` 与 `skills/tdd.md`：

1. **Red → Green → Refactor**
2. **同一 TASK 连续 5 次红灯** → 人介入（`4p12s-implementation-execution`）
3. **无新鲜验证证据不宣称完成**（Superpower）
4. 测试文件与源文件同目录：`.test.ts` / `.test.tsx`（已入库，`.gitignore` 不忽略测试文件）

## 测试命令

| 命令 | 说明 |
|------|------|
| `npm run test` | 前后端单元测试（Vitest run） |
| `npm run test:watch` | 监视模式 |
| `npm run test:e2e` | Playwright（自动起 Vite webServer） |
| `npm run lint` | ESLint（CI 门禁） |

## 门禁与 4p12s

| 步骤 | 测试门禁 | Skill |
|------|----------|-------|
| ⑥ 验证计划 | 写明单测/集成/E2E 与禁 Mock 节点 | `4p12s-verification-plan` |
| ⑧ 执行开发 | TDD；5 次红灯升级 | `4p12s-implementation-execution` |
| ⑨ 集成测试 | 仅 Mock = 假完成 | `4p12s-integration-test` |
| ⑩ E2E | 主路径禁 Mock | `4p12s-e2e-test` |
| ⑪ Git | 测试摘要写入 commit | `4p12s-git-push` |

验证产物：[`designdoc/verification/`](../../designdoc/verification/)（`verification-result.md` 含 ⑨ 集成与 ⑩ E2E 结果）
