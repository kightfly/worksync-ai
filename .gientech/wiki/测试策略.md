## 护栏约定

| 项 | 约定 |
|----|------|
| 单测 | Vitest + Testing Library |
| E2E | Playwright（交付门禁；禁 Mock 假完成） |
| 纪律 | TDD 先行：先失败测试，再写生产代码（见 `tdd.mdc`） |
| 顺序 | 单测 → 集成 → E2E → Git → 部署 |
| 覆盖率目标 | 80%+（NFR-003） |

## 当前阻塞

- 无根 `package.json`；`npm test` / `lint` / `e2e` 脚本 **尚不存在**（预期 ⑧ 创建）
- 无 `apps/` 测试目录（预期 ⑧ 创建）

详见 [`delivery-state.md`](../../designdoc/delivery/delivery-state.md) 全局阻塞项。

## 禁止（假完成）

- 只跑单测就宣称功能完成
- 集成/E2E 全 Mock 却称真实链路验证通过
- 未更新 delivery-state 却称十二步已推进
