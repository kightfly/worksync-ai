## 环境要求

| 工具 | 最低版本 | 说明 |
|------|---------|------|
| Node.js | 20.0.0+ | 根 `package.json` `engines` |
| npm | 10+ | npm Workspace |
| PostgreSQL | 15+ | **📋 业务 DB 落地后必需**；当前护栏可不装 |
| Git | 2.30+ | 版本控制 |
| Playwright Chromium | — | 首次 `npm run test:e2e` 前自动/手动安装 |

## 安装步骤

### 1. 克隆仓库

```bash
git clone git@github.com:kightfly/worksync-ai.git
cd worksync-ai   # 或你的本地目录名（如 GienHarness）
```

### 2. 安装依赖

```bash
npm install
```

Monorepo 使用 npm Workspace。根目录 `npm install` 会安装 `apps/web`、`apps/api` 依赖。`packages/*` 尚未创建，无需关心。

### 3. 配置环境变量（可选，护栏阶段）

```bash
cp .env.example .env
```

当前 [`.env.example`](../../.env.example) 内容：

```env
PORT=3000
DATABASE_URL=postgresql://user:password@localhost:5432/ai_harness
VITE_API_BASE_URL=http://localhost:3000
```

| 变量 | 护栏阶段 | 说明 |
|------|----------|------|
| `PORT` | 可选 | API 默认 3000 |
| `DATABASE_URL` | 📋 暂不需要 | Auth/DB TASK 完成后需要 |
| `VITE_API_BASE_URL` | 📋 暂不需要 | 前端接 API 时使用 |
| `JWT_SECRET` | 📋 未写入 example | Auth 实现时补充 |

> **修订**：此前文档将 `JWT_SECRET` 写为必配；当前 **无 JWT 实现**，不必配置。

### 4. 初始化数据库（📋 尚未可用）

脚本已在 `apps/api/package.json` 声明，但 **`src/db/`、Drizzle Schema、seed 尚未落地**：

```bash
# 以下命令在 DB 层 TASK 完成前可能失败 — 勿作为护栏验收项
npm run db:migrate
npm run db:seed
```

完成标准见 [`tasks.md`](../../designdoc/specs/tasks.md) Phase B（如 TASK-B201）。

### 5. 启动开发服务器

**分别启动（推荐，与当前脚本一致）：**

```bash
npm run dev -w apps/web   # http://localhost:5173
npm run dev -w apps/api   # http://localhost:3000
```

根目录 `npm run dev` 在 Windows 下并行行为因 shell 而异；不确定时用上面两条。

**护栏验证：**

```bash
curl http://localhost:3000/health
# → {"status":"ok"}

# 浏览器打开 http://localhost:5173 → ログイン占位页
```

## 验证安装（护栏推荐）

与 CI **quality** job 对齐的一键检查：

```bash
npm run lint && npm run typecheck && npm run test && npm run test:e2e
```

首次 E2E 若缺浏览器：

```bash
npx playwright install chromium
cd apps/web && npx playwright install chromium
```

通过后启动 `dev -w apps/web` / `dev -w apps/api` 做人工冒烟。

## 常见问题

### `db:migrate` / `db:seed` 失败

**预期行为**：Schema 与 `src/db/seed.ts` 尚未实现。先完成 Phase B 数据层 TASK，或跳过此步仅跑护栏。

### 数据库连接失败

仅在已配置 `DATABASE_URL` 且运行依赖 DB 的代码时出现。护栏阶段只需 `/health` 与前端静态页。

### npm install 失败

```bash
node --version   # 需 ≥ 20
```

Peer 冲突时可查 lockfile；本项目 web 使用 `@testing-library/react@16` 以兼容 React 19。

### 端口冲突

- 前端：`apps/web/vite.config.ts` → `server.port`（5173）
- 后端：`.env` 的 `PORT` 或默认 3000

### E2E 失败

本地先跑 `npm run test:e2e`；Playwright 会通过 `webServer` 自动启动 Vite。
