## 简介

本快速入门指南旨在帮助新开发者快速搭建 **AI Harness - 勤怠・タスク管理** 项目的本地开发环境。该系统是一个基于 **Node.js + TypeScript** 全栈技术的「勤怠・タスク管理」迷你后台系统，支持用户认证、任务管理（创建、查看、更新、删除）、打卡记录管理与时区转换（UTC 存储，Asia/Tokyo 展示）等核心功能。

来源：[README.md](../../README.md)、[AGENTS.md](../../AGENTS.md)

## 系统要求

在开始之前，请确保您的系统满足以下要求：

- **Node.js**: v20.0.0 或更高版本
- **npm**: v10.0.0 或更高版本
- **PostgreSQL**: 15 或更高版本
- **内存**: 至少 4GB RAM
- **磁盘空间**: 至少 1GB 可用空间
- **网络**: 稳定的互联网连接
- **操作系统**: Windows 11、macOS、Linux

来源：[README.md](../../README.md)、[package.json](../../package.json)

## 项目克隆

首先，您需要克隆项目到本地开发环境：

```bash
git clone <项目仓库地址>
cd GienHarness
```

## 环境准备

### 1. 安装 Node.js 20+

确保您的系统已安装 Node.js 20.0.0 或更高版本：

```bash
node -v
npm -v
```

如果未安装，请从 [Node.js 官网](https://nodejs.org/) 下载并安装。

### 2. 安装 PostgreSQL

项目依赖 PostgreSQL 15+ 数据库。您可以从 [PostgreSQL 官网](https://www.postgresql.org/download/) 下载并安装。

### 3. 验证安装

```bash
node -v
# 输出：v20.x.x 或更高

npm -v
# 输出：10.x.x 或更高

psql --version
# 输出：psql (PostgreSQL) 15.x 或更高
```

## 数据库服务启动

项目依赖 PostgreSQL 数据库。您需要配置数据库连接。

### 配置数据库连接

1. 复制环境变量配置文件：

```bash
cp .env.example .env
```

2. 编辑 `.env` 文件，配置数据库连接信息：

```env
DATABASE_URL=postgresql://username:password@localhost:5432/ai_harness
```

### 初始化数据库

首次启动时，需要执行数据库迁移：

```bash
npm run db:migrate
```

这将使用 Drizzle ORM 创建所需的数据库表结构。

### 种子数据（可选）

如果需要初始测试数据，可以运行：

```bash
npm run db:seed
```

来源：[README.md](../../README.md)、[apps/api/package.json](../../apps/api/package.json)

## 项目导入到 IDE

### IntelliJ IDEA / WebStorm 导入

1. 打开 IntelliJ IDEA 或 WebStorm
2. 选择 "File" -> "Open..."
3. 浏览到项目根目录 `GienHarness` 并选择
4. IDE 会自动识别为 Node.js 项目
5. 等待依赖安装完成

### VS Code 导入

1. 打开 VS Code
2. 选择 "File" -> "Open Folder..."
3. 选择项目根目录 `GienHarness`
4. 安装推荐扩展（TypeScript、ESLint、Prettier 等）

### 安装依赖

在项目根目录下执行：

```bash
npm install
```

这将安装所有工作区（apps/web、apps/api、packages/*）的依赖。

## 构建和运行项目

### 开发模式

启动开发服务器（前后端同时运行）：

```bash
npm run dev
```

该命令会同时启动：
- 前端开发服务器（Vite）
- 后端开发服务器（Fastify + tsx）

如果需要单独启动某个服务：

```bash
# 只启动前端
npm run dev -w apps/web

# 只启动后端
npm run dev -w apps/api
```

来源：[README.md](../../README.md)、[package.json](../../package.json)

### 构建项目

生产构建：

```bash
npm run build
```

该命令会：
1. 构建前端应用（Vite build）
2. 编译后端 TypeScript 代码

### 运行应用程序

构建完成后，启动生产服务器：

```bash
npm run start -w apps/api
```

### 验证应用启动

应用启动后，您应该能看到类似以下的日志输出：

```
Server listening on http://localhost:3000
```

前端开发服务器通常在 `http://localhost:5173`（Vite 默认端口）。

来源：[README.md](../../README.md)

## 故障排除

### 常见问题及解决方案

#### 1. 端口冲突

如果默认端口（前端 5173、后端 3000）被占用，可以在相应的配置文件中修改端口：
- 前端：`apps/web/vite.config.ts`
- 后端：`apps/api/src/index.ts` 或通过环境变量配置

#### 2. 数据库连接失败

检查 PostgreSQL 服务是否正常运行：

```bash
# Windows (PowerShell)
Get-Service -Name postgresql*

# Linux/macOS
sudo systemctl status postgresql
```

检查 `.env` 文件中的数据库连接配置是否正确。

#### 3. 内存不足

增加 Node.js 堆内存：

```bash
# Windows (PowerShell)
$env:NODE_OPTIONS="--max-old-space-size=4096"
npm run dev

# Linux/macOS
export NODE_OPTIONS="--max-old-space-size=4096"
npm run dev
```

#### 4. npm 构建失败

清理并重新安装依赖：

```bash
# 删除 node_modules 和锁文件
rm -rf node_modules package-lock.json
rm -rf apps/*/node_modules
rm -rf packages/*/node_modules

# 重新安装
npm install
```

#### 5. IDE 导入问题

- 确保已安装 Node.js 20+ 并配置正确的 JDK（如需）
- 检查 TypeScript 版本设置（项目使用 TypeScript 5.3+）
- 重新导入项目并刷新依赖

#### 6. 数据库迁移失败

确保 PostgreSQL 服务已启动，并且 `.env` 文件中的 `DATABASE_URL` 配置正确：

```bash
# 检查数据库连接
psql -h localhost -U <username> -d ai_harness

# 重新运行迁移
npm run db:migrate
```

#### 7. 测试失败

如果测试失败，检查：
- 数据库是否已正确初始化
- 是否运行了种子数据（如测试依赖初始数据）
- 测试环境配置是否正确

### 日志查看

- 前端日志：在浏览器开发者工具的 Console 中查看
- 后端日志：在终端中查看，或查看应用日志文件（如配置了文件日志）
