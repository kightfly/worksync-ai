## 部署流程概览

```
push / PR / workflow_dispatch
        ↓
   job: quality
   lint → typecheck → test → E2E 冒烟
        ↓ 通过
   job: deploy-test（main/master push 或手动）
   build → 上传 Artifact → Step Summary
        ↓
   人工/脚本部署 Artifact → 测试环境 URL
        ↓
   证据写入 deploy-log.md（4p12s ⑫）✅
```

> **当前**：流水线生成**可构建产物与摘要**；本地 Artifact 等价部署已完成（见 `deploy-log.md`）。公网 hosting URL 为可选增强项。

## CI/CD

### 配置文件

[`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)

| Job | 步骤 | 触发 |
|-----|------|------|
| **quality** | `npm install` → **lint** → typecheck → test → Playwright e2e | push、PR、`workflow_dispatch` |
| **deploy-test** | `npm run build` → 上传 Artifact → `write-deploy-summary.mjs` | quality 成功后，且为 `main`/`master` push 或手动 dispatch |

### 质量门禁（合并前须通过）

1. `npm run lint` — 0 warnings  
2. `npm run typecheck`  
3. `npm run test`  
4. `npm run test:e2e` — 登录页冒烟  

本地等价：

```bash
npm run lint && npm run typecheck && npm run test && npm run test:e2e && npm run build
# build 顺序：domain → infrastructure → web → api
```

### deploy-test 产物

| Artifact 名 | 内容 | 保留 |
|-------------|------|------|
| `test-env-web-<sha>` | `apps/web/dist` | 14 天 |
| `test-env-api-<sha>` | `apps/api/dist` | 14 天 |

GitHub Actions 运行页 → **Deploy Test Environment** job → **Summary** 含 commit、Artifact 名、本地验证命令。

## 手动部署 Artifact（临时测试环境）

从 Actions 下载 Artifact 后：

```bash
# API
cd apps/api && node dist/index.js

# Web 静态资源
npx serve apps/web/dist -l 5173
```

验证：`curl http://localhost:3000/health` → `{"status":"ok"}`；浏览器打开 `http://localhost:5173` 见ログイン占位页。

## 故障排查

| 问题 | 排查 |
|------|------|
| CI lint 失败 | 本地 `npm run lint`；查 ESLint 输出 |
| CI e2e 失败 | 本地 `npm run test:e2e`；Playwright 是否安装 Chromium |
| API 无法启动 | 端口占用；`PORT` 环境变量 |
| 前端白屏 | 构建产物是否完整；静态服务器路径 |
| DB 相关脚本失败 | **正常**：Schema 未落地前 `db:migrate` 可能不可用 |
| JWT 失败 | Auth 未实现或 `JWT_SECRET` 未配置 |
