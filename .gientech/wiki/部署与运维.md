## 解锁 ⑫ 所需最小条件

1. 选定托管（任选）：Render / Railway / Fly.io / Cloud Run 等，能跑 Node 20
2. 配置 Secret：`DATABASE_URL`、`JWT_SECRET`、`API_PORT`（或平台 PORT）
3. Web 构建时设置 `VITE_API_BASE_URL=<公开 API 根 URL>`
4. 发布后留下可访问 URL，并写入 `deploy-log.md`
5. 冒烟：`GET /health` → `{"status":"ok"}`；登录 demo 用户

## 建议手动部署规程（有托管后）

```bash
# 1. 构建
npm ci
npm run build

# 2. 迁移 / 种子（对测试库）
npm run db:migrate
npm run db:seed

# 3. 启动 API（示例）
# API_PORT / PORT 由平台注入
node apps/api/dist/server.js

# 4. Web：将 apps/web/dist 静态托管，或 Vite preview / Nginx
```
