## 架构位置（目标）

```
请求 → 中间件（认证/限流） → 路由 → Service → Repository → Drizzle ORM → PostgreSQL
```

**当前**：`请求 → GET /health`（无中间件链、无 DB）。

基础设施层位于 Service 之下，封装所有外部交互细节，使业务逻辑不依赖具体技术实现。模块边界见 [`AGENTS.md`](../../../AGENTS.md) 与 [架构总览](../架构总览.md)。
