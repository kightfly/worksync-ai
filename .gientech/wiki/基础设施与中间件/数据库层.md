## 概述

AI Harness 使用 PostgreSQL 作为持久化存储，通过 Drizzle ORM 访问。**当前 API 未连接数据库**；`GET /health` 不探测 DB。

## 连接配置（规划）

### 环境变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `DATABASE_URL` | PostgreSQL 连接字符串 | `postgresql://user:password@localhost:5432/ai_harness` |

见根目录 [`.env.example`](../../../.env.example)。格式：

```
postgresql://用户名:密码@主机:端口/数据库名
```

### 驱动与连接池

仓库已安装 **`pg`**（非 `postgres.js`）。推荐 Drizzle 适配器：

```typescript
// packages/infrastructure/db/client.ts（规划）
import { drizzle } from 'drizzle-orm/node-postgres';
import pg from 'pg';
import * as schema from './schema';

const pool = new pg.Pool({
  connectionString: process.env.DATABASE_URL,
  max: 10,
  idleTimeoutMillis: 20_000,
  connectionTimeoutMillis: 10_000,
});

export const db = drizzle(pool, { schema });
```

> 若改用 `postgres.js`，须额外安装 `postgres` 并使用 `drizzle-orm/postgres-js`；**以当前 `package.json` 中的 `pg` 为准**。

## 数据库初始化（规划）

本地开发就绪后：

```bash
# 1. 创建数据库（示例）
createdb ai_harness

# 2. 配置 .env 中 DATABASE_URL

# 3. 执行迁移（📋 schema 落地后）
npm run db:migrate

# 4. 种子数据（📋 seed.ts 落地后）
npm run db:seed
```

当前执行 `db:migrate` / `db:seed` 会因缺少 schema / seed 文件而失败。

## 事务处理（规划）

Service 层事务边界示例：

```typescript
await db.transaction(async (tx) => {
  await tx.insert(users).values(newUser);
  await tx.insert(tasks).values(newTask);
});
```

## 时区配置

- PostgreSQL 会话建议 UTC
- `TIMESTAMPTZ` 字段以 UTC 存储
- `work_date` 使用 `DATE`，按 Asia/Tokyo 日历日计算

详见 `.cursor/rules/timezone.mdc` 与 [数据模型](../数据模型/AttendanceRecord.md)。

## 健康检查（规划）

业务就绪后，可扩展 `/health` 或增加 `/health/db`：
