## JWT 认证中间件（📋）

### 功能

- 验证 `Authorization: Bearer <token>` 头
- 解析 JWT Payload，注入 `request.user`
- Token 无效或过期返回 401

### 规划实现

```typescript
import fp from 'fastify-plugin';
import jwt from 'jsonwebtoken';

async function authMiddleware(fastify: FastifyInstance) {
  fastify.decorateRequest('user', null);

  fastify.addHook('onRequest', async (request, reply) => {
    const authHeader = request.headers.authorization;
    if (!authHeader?.startsWith('Bearer ')) {
      return reply.status(401).send({
        error: 'UNAUTHORIZED',
        message: '認証が必要です',
      });
    }
    try {
      const token = authHeader.slice(7);
      request.user = jwt.verify(token, process.env.JWT_SECRET!);
    } catch {
      return reply.status(401).send({
        error: 'UNAUTHORIZED',
        message: 'トークンが無効です',
      });
    }
  });
}

export default fp(authMiddleware);
```

> `design.md` 错误响应为 `{ error, message }` 形态；若项目统一为 `{ success, error: { code, message } }`，实现时择一并在 [API 参考](../API参考/API参考.md) 回写。

## 全局错误处理（📋）

与 `design.md` 对齐的错误分类：

| 错误类 | HTTP | 错误代码 |
|--------|------|----------|
| `ValidationError` | 400 | `VALIDATION_ERROR` |
| `UnauthorizedError` | 401 | `UNAUTHORIZED` |
| `NotFoundError` | 404 | `NOT_FOUND` |
| 其他 | 500 | `INTERNAL_ERROR` |

```typescript
app.setErrorHandler((error, request, reply) => {
  if (error instanceof ValidationError) {
    return reply.status(400).send({
      error: 'VALIDATION_ERROR',
      message: '入力内容に不備があります',
      details: error.details,
    });
  }
  app.log.error(error);
  return reply.status(500).send({
    error: 'INTERNAL_ERROR',
    message: 'サーバーエラーが発生しました',
  });
});
```

规划路径：`apps/api/src/plugins/error-handler.ts`（或等价目录）。
