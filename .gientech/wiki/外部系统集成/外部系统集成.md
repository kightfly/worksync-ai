## 数据库（PostgreSQL）— 📋

### 连接方式（规划）

- 驱动：**`pg`** + `drizzle-orm/node-postgres`（见 [数据库层](../基础设施与中间件/数据库层.md)）
- 连接字符串：`DATABASE_URL`
- 连接池：规划最大 10 连接

本地需：PostgreSQL 实例、`createdb`、Schema 迁移落地后 `npm run db:migrate`。

## JWT 认证 — 📋

### 规划配置

| 参数 | 值 | 说明 |
|------|-----|------|
| 算法 | HS256 | 对称加密 |
| 密钥 | `JWT_SECRET` 环境变量 | 实现时加入 `.env.example`；建议 ≥ 32 字符 |
| 有效期 | 24h | Access Token |
| Payload | `{ userId, email }` | 最小化 |

### Token 流程（规划）

```
登录 → AuthService 签发 JWT → 客户端存储 → Authorization: Bearer → 中间件验证
```

详见 [认证 API](../API参考/认证API.md)、[中间件](../基础设施与中间件/中间件.md)。
