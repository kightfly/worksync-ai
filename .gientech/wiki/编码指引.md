## 异常处理（设计契约 📋）

后端统一错误模型见 `design.md`。实现业务 API 时采用：

| 类别 | HTTP | 错误代码 | 日文消息（示例） |
|------|------|---------|------------------|
| 未认证 | 401 | `UNAUTHORIZED` | 認証が必要です |
| 凭证错误 | 401 | `INVALID_CREDENTIALS` | メールアドレスまたはパスワードが正しくありません |
| 禁止 | 403 | `FORBIDDEN` | この操作は許可されていません |
| 不存在 | 404 | `NOT_FOUND` | リソースが見つかりません |
| 校验失败 | 400 | `VALIDATION_ERROR` | 入力データが正しくありません |
| 冲突 | 409 | `CONFLICT` | リソースが競合しています |
| 服务器错误 | 500 | `INTERNAL_ERROR` | システムエラーが発生しました |

```typescript
interface ErrorResponse {
  success: false;
  error: {
    code: string;
    message: string; // 日文
    details?: object[];
  };
}
```

## 时区规则

遵循 `.gientech/rules/timezone.mdc`：

| 场景 | 规则 |
|------|------|
| 数据库存储 | UTC（`TIMESTAMP WITH TIME ZONE`） |
| API | ISO 8601，带时区 |
| 前端展示 | **Asia/Tokyo** |
| 业务「工作日」 | 按东京日历日（打卡、截止日期） |

实现时集中使用共享日期工具，避免多处手写转换。

## 安全编码

遵循 `.gientech/rules/security.mdc`：

| 规则 | 说明 | 现状 |
|------|------|------|
| 输入校验 | API 用 Zod | 📋 业务路由未实现 |
| SQL | Drizzle 参数化 | 📋 ORM 未接入 |
| XSS | React 默认转义 | ✅ 占位 UI |
| 密码存储 | bcrypt 哈希 | 📋 Auth TASK |
| 密码长度（产品） | **最少 6 字符** | PRD BR-002；与 UI `minLength={6}` 一致 |
| JWT | HS256，`JWT_SECRET` 环境变量 | 📋 Auth TASK |
| 密钥 | 禁止提交 `.env` | ✅ `.gitignore` |

> **修订**：设计文档中 bcrypt cost ≥ 12 仍为目标；**产品校验**以 PRD「6 字符以上」为准，API 与 zod schema 须一致。
