## 简介

GienHarness 是用于练习 **AI Agent 在约束下按 4p12s 可靠交付** 的 Harness 项目。当前分支 `replay/4p12s-from-design` 从整体设计重跑四阶十二步。

| 项 | 说明 |
|----|------|
| **项目名称** | GienHarness |
| **分支** | `replay/4p12s-from-design` |
| **目标系统** | 日文界面「勤怠・タスク管理」迷你后台 |
| **业务输入** | [`designdoc/整体设计.md`](../../designdoc/整体设计.md)（v1.0.0-replay） |

## 本期范围（摘要）

来源：[整体设计.md §1](../../designdoc/整体设计.md)

**做**：
- 用户认证（登录/登出）与受保护路由
- タスク CRUD 与状态机（BR-007～009）
- 打刻一覧与日次集計（只读；seed 初始化）
- UTC 存储 / Asia/Tokyo 展示
- 质量门禁：单测 → 集成 → E2E → Git → 部署证据

**不做**：
- 出勤/退勤 UI 与 `POST /api/attendance`
- 多租户、SSO、审批流
- 擅自更换固定技术栈

## 固定技术栈

| 层 | 技术 |
|----|------|
| 前端 | React 19 + TypeScript + Vite + React Router |
| 表单 | react-hook-form + zod（日文校验文案） |
| 后端 | Node.js + TypeScript + Fastify |
| DB | PostgreSQL + Drizzle ORM |
| 测试 | Vitest + Testing Library + Playwright (E2E) |
| 质量 | ESLint + Prettier + TypeScript strict |
| 认证 | JWT + bcrypt（`SALT_ROUNDS=10`） |
